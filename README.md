# 🚆 Pakistan Railways – Interactive Navigation Menu

A responsive and stylish navigation bar for a website themed around **Pakistan Railways**. The navbar is fixed to the top, changes background color on scroll, and is laid over a train-themed background image for a visually rich UI.

## 🌐 Features

- 📌 **Fixed Navigation Bar**  
  Always visible at the top of the page.

- 🎨 **Stylish Background & Fonts**  
  Uses a full-page background image (`train.png`) and smooth color transitions.

- 🖱️ **Hover Effects**  
  Navigation items highlight when hovered.

- 📱 **Responsive Design**  
  Viewport meta tag ensures mobile-friendliness.

- 🧠 **Scroll Detection Script**  
  Dynamically changes the navbar’s background color when scrolling.

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **Vanilla JavaScript**

## 📁 How to Use

1. Clone or download this project folder.
2. Make sure the image file `train.png` is in the same directory as the `.html` file(you can choose image of your owm as per your choice and add the link in code).
3. Open `index.html` in your browser to see the live navigation menu in action.
